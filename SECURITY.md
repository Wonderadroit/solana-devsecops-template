# Security Policy

## Scope

This repository contains security-analysis automation and development tooling. It is intended for authorized assessment of code and systems that you own or have explicit permission to test.

## Reporting a vulnerability

If you discover a security issue in this repository itself, please avoid publishing exploit details in a public issue. Contact the repository owner privately through the contact information on the GitHub profile and include:

- A concise description of the issue
- Affected file or component
- Reproduction steps or proof of concept, where appropriate
- Potential impact
- Suggested remediation, if known

## Responsible use

The tools in this repository are not authorization to test third-party systems. Always follow the applicable scope, rules, and laws before conducting security testing.
