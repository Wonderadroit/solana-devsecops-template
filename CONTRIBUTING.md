# Contributing

Contributions are welcome when they improve the reliability, clarity, or security of the project.

## Before contributing

1. Read the repository documentation.
2. Confirm that changes are reproducible locally or in CI.
3. Keep security claims evidence-based.
4. Do not add secrets, credentials, private keys, or sensitive target data.

## Pull requests

Please include:

- A clear description of the change
- Why the change is needed
- Testing or validation performed
- Any security or compatibility considerations

Keep pull requests focused and avoid unrelated formatting or dependency changes.
